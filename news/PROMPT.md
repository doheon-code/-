# 데일리 정치·경제 브리핑 작성 지침

매일 예약 실행(Routine)이 이 파일을 읽고 그대로 따릅니다. 내용을 바꾸고 싶으면 이 파일만 고치면 됩니다.

## 할 일

1. 기준일: 한국 시간(KST) 오늘 날짜. 대상은 **직전 24시간**의 뉴스.
2. `WebSearch`로 아래 네 영역을 각각 2~3번 이상 검색한다 (영어·한국어 모두).
   - 🌍 세계 정치 (전쟁·외교·정상회담·선거)
   - 💹 세계 경제·시장 (미국 증시, 연준·주요 중앙은행, 유가, 달러, 미·중 무역)
   - 🇰🇷 한국 정치 (대통령실, 국회·여야, 외교·안보, 남북관계)
   - 🇰🇷 한국 경제 (코스피·환율, 수출·반도체, 물가·금리, 정부 정책, 주요 기업)
3. `news/briefings/YYYY-MM-DD.md` 파일을 아래 형식으로 작성한다.
4. `news/README.md`의 "최근 브리핑" 목록 맨 위에 새 날짜 링크를 추가한다 (최근 14개만 유지).
5. `python3 news/build_site.py` 를 실행해 `news/site/briefings.json` 을 갱신한다.
6. 커밋 후 푸시한다.
7. 웹페이지를 갱신한다 (Artifact 도구, URL: https://claude.ai/artifact/G2cofu9uoG3YaKEeYcKMP2).
   - 먼저 `action: "read"` 로 이 URL을 읽고, 이어서 `path: "briefings.json"` 으로 한 번 더 읽는다 (읽지 않으면 덮어쓰기가 거부됨).
   - 그다음 `url` 에 위 주소, `file_path` 에 `news/site/index.html`, `files` 에 `{"briefings.json": "news/site/briefings.json"}` 을 넣어 publish 한다. `icon` 은 넣지 않는다. 새 URL이 생기면 안 된다.
8. 세션의 마지막 답변은 "오늘의 핵심 3줄" + 파일 경로로 짧게 끝낸다 (이 내용이 알림으로 간다).

## 작성 원칙

- 한국어로 작성. 고유명사는 필요하면 영문 병기.
- 영역별 3~5개 항목, 항목마다 1~3문장. **사실 → 의미(왜 중요한가)** 순서.
- 숫자(지수, 금리, 환율, 유가)는 검색 결과에 나온 값만 쓰고, 출처마다 다르면 범위로 쓰거나 생략한다. 추측으로 숫자를 만들지 않는다.
- 확인되지 않은 소식은 쓰지 않거나 "보도에 따르면"으로 표시한다.
- 정치적으로 한쪽에 치우친 표현을 피하고, 쟁점은 양측 입장을 함께 적는다.
- 주말·공휴일로 시장이 닫혀 있으면 마지막 거래일 기준임을 명시한다.
- 항목 끝에 출처 링크를 `([매체](URL))` 형태로 단다.

```markdown
|---|---|---|

- ...

## 🇰🇷 한국 경제
- ...

*자동 생성: 검색 기반 요약이며 투자 판단의 근거로 쓰지 마세요.*
```
